# vault-plugin-meilisearch

A HashiCorp Vault secrets engine plugin that dynamically generates [Meilisearch](https://www.meilisearch.com/) API keys.

## Features

- **Dynamic credentials**: Generates Meilisearch API keys on demand with automatic expiration
- **Role-based access**: Define roles with specific actions, indexes, and TTLs
- **Automatic revocation**: Keys are deleted from Meilisearch when leases expire or are revoked
- **Lease renewal**: Supports Vault lease renewal

## Usage

### Build

```bash
make build
```

### Register the plugin with Vault

```bash
# Get the SHA256 of the plugin binary
SHA256=$(shasum -a 256 vault-plugin-meilisearch | cut -d' ' -f1)

# Register the plugin
vault plugin register -sha256=$SHA256 secret vault-plugin-meilisearch

# Enable the secrets engine
vault secrets enable -path=meilisearch vault-plugin-meilisearch
```

### Configure the connection

```bash
vault write meilisearch/config \
  host="http://localhost:7700" \
  master_key="your-master-key"
```

### Create a role

Roles define templates for generating API keys. The `actions` and `indexes` fields map directly to [Meilisearch key permissions](https://www.meilisearch.com/docs/reference/api/keys).

```bash
# Search-only role scoped to specific indexes
vault write meilisearch/roles/search-only \
  actions="search" \
  indexes="movies,books" \
  ttl=1h \
  max_ttl=24h

# Admin role with full access
vault write meilisearch/roles/admin \
  actions="*" \
  indexes="*" \
  ttl=8h \
  max_ttl=24h

# Documents role with granular permissions
vault write meilisearch/roles/documents \
  actions="documents.add,documents.get,documents.delete" \
  indexes="products,orders" \
  description="Document management access" \
  ttl=4h
```

### Generate credentials

```bash
vault read meilisearch/creds/search-only
```

Returns:


### Revoke credentials

```bash
# Revoke a specific lease
vault lease revoke meilisearch/creds/search-only/abcd1234

# Revoke all leases for a role
vault lease revoke -prefix meilisearch/creds/search-only
```

## API Paths

| Path | Method | Description |
|------|--------|-------------|
| `config` | POST | Configure the Meilisearch connection |
| `config` | GET | Read the current configuration (master key is not returned) |
| `config` | DELETE | Delete the configuration |
| `roles/:name` | POST | Create or update a role |
| `roles/:name` | GET | Read a role |
| `roles/:name` | DELETE | Delete a role |
| `roles/` | LIST | List all roles |
| `creds/:name` | GET | Generate a new API key for the named role |

## Role Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `actions` | string (CSV) | yes | Meilisearch actions: `search`, `documents.*`, `indexes.*`, `*`, etc. |
| `indexes` | string (CSV) | yes | Index UIDs or patterns: `movies`, `products_*`, `*` |
| `description` | string | no | Description set on generated keys |
| `ttl` | duration | no | Default lease TTL |
| `max_ttl` | duration | no | Maximum lease TTL |

## Supported Meilisearch Actions

`search`, `documents.*`, `documents.add`, `documents.get`, `documents.delete`, `indexes.*`, `indexes.create`, `indexes.get`, `indexes.update`, `indexes.delete`, `tasks.*`, `settings.*`, `stats.*`, `dumps.*`, `snapshots.*`, `keys.*`, `*`
